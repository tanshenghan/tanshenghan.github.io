3.2 / 收入怎样转成利润

消费端与工业端的五条经营线索

智能家居：渠道、产品和海外品牌

把空调、冰洗及厨小电卖给家庭。销量、实现净价、产品组合和渠道费用共同决定利润；自有品牌需要持续投入品牌、售后和本地供应链。

公司披露H1海外OBM收入占智能家居海外收入超过50%；这是特定业务和地域的比例，不是集团海外或总收入的一半。销售费下降与DTC渠道变革相关，但毛利率仍承压。

验证点：跟踪国内同口径净价、库存与回款，以及海外品牌增长是否覆盖本地化投入。 美的集团2026年半年度报告 PDF p27、29、30、50、52 · 美的2026中报英文原件 PDF p84

楼宇科技：设备加系统解决方案

覆盖商用暖通、电梯和楼控等。项目获取、技术与交付、节能服务影响订单与利润，不能将行业需求直接视为公司收入。

H1楼宇科技收入与毛利均增长；公司披露数据中心冷源、CDU、末端及运维产品布局。液冷收入和净利未单独完整披露，不能给整条业务套用AI高增长估值。

验证点：跟踪新签项目的回款、验收和毛利，以及海外并购整合。 美的集团2026年半年度报告 PDF p35、36、37、38、39、40、42、52

机器人与自动化：规模与利润分开看

工业机器人本体、系统集成、智能物流和医疗物流面对企业资本开支周期。销售增长不一定同步转化为利润率改善。

H1机器人与自动化收入增长10.27%，毛利率20.90%、下降1.86个百分点；库卡中国收入占库卡集团超过30%。人形机器人在自有工厂推进应用，尚不能按未披露外部商业收入另加市值。

验证点：跟踪外部订单、项目交付毛利与资本回报；不把工厂试点量当付费销量。 美的集团2026年半年度报告 PDF p18、19、38、42、43、44、52

工业技术：核心零部件受下游周期影响

压缩机、电机、泵阀和部件服务家电、汽车及其他工业客户。内部配套与对外销售必须分开，价格、规模和产能利用共同影响毛利。

H1对外产品口径收入下降12.72%，毛利率14.75%；公司解释与下游国内家电尤其空调行业规模下滑相关。内部供应能力具有协同价值，但不构成额外一遍对外收入。

验证点：检验外部客户增长和盈利，避免用含内部交易的法定分部规模估对外销售。 美的集团2026年半年度报告 PDF p35、36、37、52 · 美的2026中报英文原件 PDF p83

新能源、医疗和物流：拆收益也拆权益

电网、储能、医疗影像和物流业务各有不同的资本投入、回款及股东结构。

其他商业及工业业务并非单一高利润板块，不能把收入整体视为美的归母盈利。子公司增资、集团内资金划拨及真正对外投资需按合并口径判断。

验证点：观察少数股东损益、亏损业务资本投入和外部交易；不用母公司持股控制等同100%权益。 美的集团2026年半年度报告 PDF p10、11、44、45、46、47、52

5.3 / 股东现金交叉验证

利润增长、派息与再投资约束

第1年利润采用上方正常归母；第2—5年按研究增长率增长
年度分红＝正归母利润×派息率；前五年隐含再投资回报＝增长率÷留存比例
稳定期派息率＝1−长期增长率÷长期股权再投资回报率
分红价值＝前五年分红现值＋稳定期分红现值；股权折现率必须高于长期增长率

固定当前经济股数，首年利润取上方模型；第2—5年增长5%、现金派息65%、股权折现9%，稳定期增长3%、新增留存权益回报15%，推导稳定派息80%。前五年增长/留存对应约14.29%回报，与长期回报假设相近，但公司是否达到仍需验证。65%派息给再投资和偿债留出空间；未来分红总额按公司审批执行，不能由本模型保证。

首年模型股息3.66元低于已付2025全年度4.30元，强调的是前瞻正常利润与派息能力；0.50元中期预案如获批并在预测期支付，包含在首年总额中，不在外面再加。已付末期股息也不作为未来现金重复折现。两个模型共用同一正常利润，交叉验证并不等于两套独立盈利证据。

基准稳定期价值占79.66%，对长期假设较敏感；仅把股权折现率从9%提高到10%，其余保持基准，分红价值便由76.62降到65.16元。以下可直接调整并观察。

5.4 / 固定情景与当前参数

利润、倍数和资金回报一起改变价格

固定情景不随自定义输入改变，不是统计置信区间。DDM只折现现金分红，未来回购未假设自动发生，也未作为第二笔分红再加。

PE与核心业务毛利率

当前价格要求多少盈利

隔离分母的稀释诊断

若仅把两档债全部理论转成1.72480006亿新H股，而暂不调整融资成本，盈利模型从78.76变成76.97元（90.08港元）。这是隔离股数影响的压力诊断，不是完整转股估值，也不是预测必然转换；正式转股需加入实际节省的税后融资成本。

未行权A期权按当前A价与41.44元行权价做简化库存股法，净增约596.27万股，单独诊断价值78.69元。它是价格相关的静态代理，不宣称精确IAS33稀释股数；未来现金融资、受限股归属、库存股转出和股份支付都要同步更新。

5.5 / 结论与验证

估值来自哪些可检查的假设

基准盈利价值 78.76元 / 92.17港元；25%安全边际价 59.07元 / 69.12港元。分红折现交叉值 76.62元 / 89.66港元。相比A股80.10元、H股90.45港元，两市场价格均接近基准价值，但尚未满足本报告设定的25%安全边际。

固定审慎至积极盈利价值45.45—122.70元（53.19—143.59港元），不是置信区间。组合压力同时将六类毛利率降1个百分点、正常资金收益降到45亿元、减值升到25亿元：盈利价值66.91元；再把股权折现率提至10%，分红价值55.35元。资金回报和毛利变化即使收入不变，也足以明显改变估值。

需要新证据验证的核心是：国内需求支持退坡后净价和费用能否稳定；海外自有品牌与本地制造能否形成现金；工业收入增长是否带来可归母利润；集团资金收益、偿债与资本投入是否允许持续分红。当前估值是这些假设的计算结果，不能将某个单一价格当作不变结论。

经营兑现

净价、产品结构与费用改善能否持续

观察家电毛利、DTC成本、海外品牌回款及工业客户周期，而不只看收入增长。

资本兑现

投入是否形成可持续的股东现金

观察海外制造、合资和并购的实际净投入、资产减值及少数股东权益，检验留存利润回报。

权益兑现

回购、分红、股权激励与转债同步更新

价格变化、回购交割和转股都需更新分子或分母；同一笔现金和同一份股份只计一次。
