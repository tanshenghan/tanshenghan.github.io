先明确这里的“端到端”

模型训练 ≠ 所有参数从零训练

本页按“存在针对导航任务的可学习策略或动作头”收录。LLM / VLM 通常从预训练权重开始；冻结视觉编码器、分阶段训练、外接低层控制器都很常见。表中的架构分类是阅读归纳，不代表作者对 E2E 的统一定义。

直接动作 / 轨迹

VLM 生成动作 token，或通过学习的动作头输出路点。连续环境中执行离散动作，也属于此类。

分层 / 双系统

语言规划与高频动作分工；中间通过指令、像素目标或潜在表示连接，需分别检查训练方式。

导航图策略

在给定或构建的导航图中选下一节点。保留 NaviLLM、NavGPT-2 作为早期 LLM 架构参照。

地图中间表示

以显式地图连接感知和决策；地图可能来自几何管线，也可能由网络学习生成。

轨迹头与多任务NavFoM → Qwen-RobotNav；对照 ABot-N0 / ABot-N1 的分层方式

后训练与未来预测ActiveVLN / CorrectNav；LatentPilot / FutureNav

目标跟随与多任务TrackVLA → VLingNav → LightNav-0

这是面向自训练选题的代表性目录，并非穷尽论文清单。TrackVLA 的目标跟随，以及 VLingNav 的 ObjectNav / ImageNav / 跟随任务，作为相关具身导航工作收录，与传统路线指令导航分别标注。ABot 在本页指导航模型 ABot-N0 / N1；ABot-AgentOS 属于另一类系统工作。

Towards Learning a Generalist Model for Embodied Navigation

要解决什么问题

传统 VLN 各任务独立设计动作头，难以共享导航、物体定位和语言理解能力。

设计思路基于论文的阅读归纳

把任务、当前观察、历史和输出提示组织为统一 schema，使不同具身任务都成为同一个语言模型的序列生成问题。

冻结 / 固定部分
预训练视觉编码器及预提取的物体视觉特征；并非从像素开始更新全部网络。

模块作用训练 / 使用方式

训练流程

  1. 预提取视觉特征，把导航、定位、轨迹总结和问答整理为共同的输入输出格式。
  2. 以专家轨迹进行教师强制预训练，学习观察、历史与文字输出之间的对应。
  3. 多任务微调交替使用专家轨迹与模型自身执行轨迹，减轻测试时的状态分布偏移。

推理时怎样行动

  1. 读取当前全景候选视点，编码方向与位置，并更新已访问观察的历史。
  2. 将任务 schema 和多模态特征输入语言模型，生成下一视点编号或停止。
  3. 仿真器按导航图执行视点转移；下一时刻重新观察并循环。

端到端边界：这是可训练的离散导航图策略；输出编号并不等于直接控制连续空间中的机器人，低层避障和运动控制未包含在模型内。
