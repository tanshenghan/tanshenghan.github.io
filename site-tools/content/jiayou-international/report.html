2026H1增利，先看贸易毛利的变化

2.1 / 2016—2025

从口岸服务，扩展到跨境网络与海外资产

2016—2025收入由9.57亿元增至83.77亿元，九年复合增长27.26%；归母由1.46亿元增至11.41亿元，复合增长25.69%。但2025收入和归母分别下降4.31%和10.60%，业务量与盈利不是单向上升。嘉友国际2017年年度报告 p8 嘉友国际2025年年度报告 p7

从早年的口岸、仓储和物流，逐步加入大规模贸易、海外车队及陆港资产。净资产与股本扩张、资本支出和现金周转同样决定股东回报；资本公积转增不能被当成经营价值凭空增加。

点击或用键盘选择年份查看来源；空值不是零。

2.2 / 收入与毛利结构

一元贸易收入和一元物流收入，含义不同

供应链贸易以自有名义采购、销售货物，收入包含商品价值。物流服务与陆港服务的计费单位和成本结构不同。用毛利贡献同时观察，才能避免把贸易收入扩张误认为物流服务量同比例扩大。

2017贸易迅速放量，合并收入跳升，但低毛利贸易占比提高使整体毛利率下降。后续非洲陆港收费带来新的毛利来源，PPP建造收入则有明显建设周期。2025贸易毛利率10.47%、物流26.73%、陆港59.48%，三者不能使用同一收入估值倍数。嘉友国际2017年年度报告 p16 嘉友国际2025年年度报告 p198、199

2.3 / 量、价与单位收益

分别跟踪吨数、运价与通道收费

2025年中蒙跨境综合物流服务总量超过1500万吨，其中自营主焦煤贸易700万吨，为其他客户服务的货物近800万吨；两项属于总量构成，不另加到集团业务总量上。2026H1霍尔果斯综合物流交付货量同比增长96%，但未披露可据此推算全集团平均单价的完整同口径量价表。嘉友国际2025年年度报告 p19 嘉友国际2026年半年度报告 p14

2026H1报告披露“达累快航”完成9艘整船运输项目，赞比亚萨卡尼亚相关17.26公里道路及一座收费站进入运营；这些是经营进展证据，尚不足以反推出每吨、每车或每公里的归母收益。嘉友国际2026年半年度报告 p14、18、19

业务对应量价关系不能直接这样算应继续核验
综合物流不同货种、距离和模式的货量×服务单价集团总收入÷某个口岸吨数同线路运量、价格、外包与自营成本、装载率
供应链贸易商品销量×售价；毛利取决于采购、运费及结构煤价上涨就等于毛利率上涨采购定价与售价时点、品级、存货跌价、回款
陆港与通道合规通行及服务量×实际收费，减维护和摊销项目总投资÷收入当成回收年限分项目收费量、实际入账收入、维护义务与税负

未取得覆盖十年、可勾稽的同口径业务量序列，因此不虚构十年平均吨价、每车利润或项目净利。业务总收入与毛利可以复核，项目单位收益仍有披露边界。

2.4 / 核心事件与增长引擎

把建设、运营与利润兑现分开

2016

中蒙物流、仓储构成主要利润基础

物流收入4.7519亿元、供应链贸易收入4.8173亿元；智能仓储收入1.2582亿元、毛利率76.66%，供应链贸易毛利率3.53%。收入规模不能替代盈利能力判断。

低毛利供应链贸易高速放量

上市并扩大综合物流业务

2018年2月IPO募集资金净额7.73302亿元。进入铜精矿供应链贸易，增强公铁联运、无车承运平台与信息系统。经营现金流仅428.94万元，年报归因于业务开展增加预付款。

跨境多式联运

把公路、铁路、海运、仓储、通关及装卸组合成履约方案，服务矿业及冶炼客户。口岸资产、运力组织与客户黏性提供竞争基础；车队扩张同时带来折旧、维修和调度成本。

关注新增线路能否有稳定返程货源、提升周转与资产利用率。子公司收入不能与合并分业务收入再次相加，海外运输也不等于全部陆港利润。

供应链贸易

以货权、采购和销售安排连接上游资源及下游需求，物流网络帮助履约。利润来自购销结构及综合服务效率，同时承担商品价格、供方交付和预付资金风险。

销量、报价、采购合同期限和毛利率需要一起验证。长期未履行的预付款不能因为业务有协同就忽略减值或现金沉淀。

陆港项目服务

通过已运营口岸、公路及配套设施收取相关服务费用。较高毛利包含先期投资形成的资产和权利，也要承担维护、摊销、当地政策和币种风险。

按实际权益归属识别价值。合同特许权有期限，期满移交或续约条件限制长期现金流，不能仅凭高毛利率采用永续高增长。

PPP建造服务

建设阶段按合同和会计准则确认服务收入。已披露2025及2026H1收入与成本相同，因此没有贡献本表毛利；它不是收费服务的重复收入。

资产可形成未来特许经营收益，但建设支出、履约资产和运营收费必须分别跟踪。不能把建造收入按陆港运营毛利率外推。

3.3 / 区域与项目

中蒙基础盘、非洲网络与中亚复制

中蒙与中亚

中蒙口岸和仓储是物流与贸易基础盘；霍尔果斯等中亚节点复制口岸组织能力。矿产品价格和供方履约会影响贸易现金周期，不能仅凭通关便利推断全部价差扩大。

非洲

卡萨项目、赞比亚道路、BHL车队、海运与海外仓扩充服务范围。部分设施已运营，部分尚在建设或准备阶段；未开工项目不纳入已实现利润。

3.4 / 从计划到现金

未来增量需要的证据

口岸及多式联运形成稳定货流

口岸、车队、海外仓和铁路之间可以共享客户与货源。应验证实际通关量、收入和回款，以及新设施投用是否增加维护和人员成本。

中亚复制需要本地履约能力

经验和客户关系可以迁移，土地、监管、运力与合作伙伴仍需逐项落实。不能把口岸布点数量直接折算为过去中蒙项目同等利润。

坦赞铁路具有联运协同，也有长期义务

5.2 / 从经营到归母

明确贸易毛利假设，再谈“低PE”

业务毛利 = 物流收入×毛利率 + 贸易收入×毛利率 + 陆港收入×毛利率
主营及金融税前利润 = 毛利 − 销管研 − 税金附加 − 减值预留 + 常态净金融收益
正常化归母 = 上述利润 − 对应所得税 + 权益法税后收益 − 少数股东净利
当前每股研究价值 = 未来12个月正常化归母 × 前瞻PE ÷ 股数

该模型估算的是股权价值。利息、融资成本、权益法收益及少数股东归属已进入利润，不再额外加账面现金、加联营投资账面值、减全部债务或减一次少数股东权益。前瞻PE直接用于当前价值，未把未来某年价值未经折现当作今天的价格。建造收入和其他零星业务不另造利润。

5.4 / 现金收益交叉检验

不把有限特许权一律算到永远

归母现金收益代理 = 预测归母利润 × 现金转换率
当前价值 = 前五年现金现值 + 有限期限部分第6年至到期年的现金现值 + 持续业务终值现值
持续业务终值 = 第6年持续业务现金 ÷（股权折现率 − 长期增长率）

转换率概括维持和扩张资本开支、营运资金、净融资以及归母权益归属后的现金；它是显式研究假设，不是把合并报表现金机械当作FCFE。没有再加存量净现金，也不把已预测现金中包含的利润价值重复计算。75%转换率参考了2025、2026H1及TTM的“经营现金减购建/归母”比值约66.17%、68.58%及82.79%；这些只是现金代理，尚未完整扣除股权出资等项目。默认有限期限部分25%、剩余18年，只是期限敏感性；各项目实际合同和开工运营日期不同，不能称作精确分部DCF。

有限部分到期不假设无成本续期或残值；持续业务长期增长需要现金转换率已经保留再投资。新的大额项目投入、预付款无法回收或融资偿还压力提高时，应降低转换率或加入专项模型，不能将未出资项目收益提前加入。

5.5 / 条件与验证

估值最依赖的三个判断

固定基准预测归母13.72亿元，13倍前瞻PE对应13.04元/股；25%安全边际对应9.78元。审慎—积极区间为5.86—21.29元。12.00元快照低于基准估值，但未达到所选安全边际价。

默认现金收益模型约8.61元/股，使用75%现金转换率、前五年8%增长、12%股权折现率及有限期限设置。它低于PE结果，说明13倍PE还需要较强的现金转化或增长兑现，不能只凭约12.5倍TTM PE认定有充分安全边际。

在13倍PE下，12元需要约12.63亿元未来12个月归母利润。维持贸易高毛利、物流利润率修复和海外投资回报，是三种不同的证据要求。全文估值以已披露业务为基础，未给尚未量化的布隆迪合作或未运营铁路先加利润。

以上为固定基准，输入改变后的结论以上方计算为准。简化PE模型没有另加现金、扣待派股利池或额外加0.28元；若采用严格除息估值，应同时调整价格和分配权，不能只调整一边。

正常化利润

贸易毛利能否跨周期保持

检查销量、采购定价与销售回款，观察2026H1利润改善是否延续；若只是短期合同价差释放，不能按高点盈利给持续增长倍数。

现金与维护

长账龄预付是否按期转货、回款

预付款、存货和合同资产与收入共同变化，维护预计负债、实际维修支出和资本投入与现金一起比较。资金回笼不及预期时，盈利倍数也应下调。

新增项目

建设、运营和分红逐项兑现

关注项目阶段、股权比例、优先融资赎回、铁路担保和合作预付款。新布局能否补足特许权到期后的现金，需要后续经营证据。
